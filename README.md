# Voca-IA 🎓🤖

Página web de orientación vocacional con un chatbot basado en Inteligencia Artificial que ofrece recomendaciones personalizadas sobre carreras profesionales para los estudiantes de la I.E. San Luis de Gaceno.

## 🚀 Tecnologías usadas

- Python + Flask
- SQLAlchemy + SQLite
- Flask-Login
- OpenRouter API (IA)
- HTML, CSS, JavaScript

## 📁 Estructura del proyecto

voca-ia/
├── app.py
├── models.py
├── requirements.txt
├── templates/
└── static/

## ⚙️ Cómo ejecutarlo

1. Clonar el repositorio
2. Crear un entorno virtual: python -m venv venv
3. Activar el entorno: venv\Scripts\activate
4. Instalar dependencias: pip install -r requirements.txt
5. Crear archivo .env con las credenciales
6. Ejecutar: python app.py
7. Abrir http://localhost:5000
